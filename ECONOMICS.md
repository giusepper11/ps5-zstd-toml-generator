# Sampled compression economics API

`economics::measure` accepts one caller-defined stratum of already eligible entries (for example a kind, extension and subtree), a `SourceTree`, an injected `Compressor` and a nonzero allocation unit in bytes. The encoder must return the complete compressed frame length for each supplied block; errors abort measurement. The stated compressor identity is caller-supplied and unverified. A caller must separately establish that the encoder and settings match the intended Forge job before drawing comparisons.

Files are ordered by size and path, then at most 16 evenly spaced files are sampled. The first, middle and final distinct 256 KiB aligned blocks are measured, including a short final block. Empty files contribute to the index model but are not compressed. A frame at least as large as its raw block is modeled as stored raw. Report the sum of `stored_sample_bytes` divided by `raw_sample_bytes` for a byte-weighted sample ratio; if the denominator is zero there is no ratio. Per-block results expose variation that an aggregate hides.

`model_index_bytes` is a stated sizing model: 32 bytes per entry, 8 bytes per logical block and UTF-8 path bytes. It is not measured output from Forge. Allocation figures round each sampled raw or stored block individually to the requested unit, a hypothetical layout rather than the actual pack filesystem layout. All totals describe sampled blocks only. They are not a prediction of final pack size or global savings; actual index layout, packing, filesystem allocation and compressor settings can differ. Runtime performance and gameplay are not assessed.

The standalone Node 24 script `scripts/sample-zstd.mjs <dump> <analysis-folder> <new-output.json>` reads `selected.txt` from a generated profile (one exact relative UTF-8 path per line). It uses `candidates/selected.txt` when present in older analysis outputs. It samples strata defined by the first two parent directories and extension, with at most 16 files per stratum and distinct first/middle/last aligned 256 KiB blocks. A global 256 MiB sample budget and 12,000-block cap may truncate later strata; inspect `truncated` and each reported sample before interpreting it. Each frame is round-tripped locally, its raw and compressed SHA-256 hashes and source stat are recorded, and frames that do not shrink are modeled raw. `--self-test` exercises window boundaries and frame roundtrips. The script writes a new JSON file only, capped below 4 MiB; it does not create a pack. Local Node/Zstd version and settings are recorded, but equivalence to Forge compression or gameplay is not established.
